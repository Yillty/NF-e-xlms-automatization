# Descrição 
Este caderno é parte de uma comissão para uma empresa de contabilidade que buscava automatizar o processo de download dos xlms de seus clientes no maranhão. O script foi feito de forma a contornar
problemas de _login_ via gov.br normalmente envolvidos nesse tipo de operação através do login manual por parte do usuário. Desta forma, embora não completamente automatizado, ele ainda é capaz de
eliminar a maior parte do trabalho envolvido no processo: 
> selecionar empresa -> adicionar mês/ano de competência -> selecionar tipo de nota fiscal -> selecionar tipo de documento -> solicitar download

O qual se mostra como extremamente moroso em escritórios com um alto número de clientes. Desta forma, o script libera capacidade operacional para que o escritório possa voltar sua atenção a questões
mais relevantes, deixando o caderno cuidar do resto. 

A opção por um caderno foi feita visando o controle do usuário, ao mesmo tempo que permite que aqueles com menor nível de instrução técnica possa utilizá-lo através das descrições providas em markdown.
